SERVICIO PRIVADO · BASE DE DATOS

        
Añadir base de datos

        

        
    
          
  • La base solo será accesible desde la red privada de este proyecto; no se publican puertos.
    • 
          
  • Los datos persistirán en un volumen Docker separado del código.
    • 
          
  • El contenedor recibe DATABASE_URL_FILE=/run/secrets/database-url; tu app debe leer el archivo e incluir el controlador correspondiente.
    • 
          
  • Al crear la base se habilita el archivo secreto sin recrear el contenedor. Reinicia la aplicación para que su proceso vuelva a intentar la conexión.
    • 
          
  • La contraseña se guarda protegida en el servidor y solo se revela tras confirmar el nombre del proyecto.
    • 
          
  • El código editable se conserva en la carpeta de proyectos; los datos se guardan en un volumen Docker privado. El panel mostrará ambas rutas al terminar.
